# thousandli.ru — правила проекта

Онлайн-школа китайского языка «Тысяча ли» (заказчица — Варвара Тимофеева).
Статика: HTML + CSS (БЭМ, токены в `:root`) + ванильный JS. Без сборки.

## Деплой
- Любой пуш в `main` / `claude/**` → GitHub Actions заливает сайт по FTPS в `www/thousandli.ru/` → https://thousandli.ru/ (индексация открыта).
- Копия /test/ убрана 2026-10-13 (шаг «Remove /test copy» в deploy.yml); на хостинге осталась только `test/video/` — исходники видео.
- Страница 404: `src/pages/404.html` (`<base href="/">`, чтобы стили грузились с любой глубины), подключена в `.htaccess` (ErrorDocument). Соцсети на ней — Telegram, MAX, почта, телефон; VK добавить, когда заказчица пришлёт ссылку.
- Видео в git нет: на прод workflow копирует `founder-ru.mp4` и постер из `test/video/` в `video/`;
  английскую запись (`test/video/Varvara English Version.mp4`) один раз сжимает в `video/founder-en.mp4` + постер (шаг «Prepare English founder video»).
- Пароли — только в GitHub Secrets и `deploy/.env` (в .gitignore). Не коммитить.

## Формы и капча
- Все формы (заявка, квиз) → `send.php` (mail на LEAD_TO, honeypot `website`).
- Stitex Captcha «Я не робот»: ключ клиента (публичный) деплой подставляет в `CAPTCHA_SITEKEY` (js/main.js), серверный — GitHub Secret `STITEX_SECRET_KEY`; нет секрета — капча выключена.
  Деплой пишет `captcha-secret.php` (в git его нет); токен приходит в поле `stitex-captcha-token`, send.php проверяет его на pulse.stitex.com.
  Контейнер в разметке — `<div class="captcha" data-captcha hidden>`.
- Квиз: на главной — «Подобрать программу»; на страницах программ (`@include quiz program="…"`, `steps summary="1"`) —
  итоговый «Подведём итог»: сводка ответов + подсказка, если по ответам лучше подходит другая программа.

## Картинки — всегда WebP
- Все растровые картинки (фото, текстуры) — только `.webp` (cwebp / Pillow, q≈80–85),
  с реальными `width`/`height`. Ниже первого экрана — `loading="lazy" decoding="async"`.
- Иконки и декор с контуром — SVG.
- Исключения, где формат диктует платформа: `img/og-image.jpg` (соцсети),
  `favicon.ico`, `apple-touch-icon.png`, `img/icons/*.png` (manifest).

## Видео
- Исходники лежат на хостинге в `test/video/`. Сжатие — workflow **Optimize video on hosting**
  (ручной запуск: `src` = имя исходника, `dst` = латинское имя). Результат `<dst>.mp4` + `<dst>-poster.webp`.

## SEO
- Сайт готов к индексации: title/description, canonical, OG/Twitter, JSON-LD
  (EducationalOrganization, WebSite, FAQPage), `robots.txt`, `sitemap.xml`, manifest, иконки.
- **Копия /test закрыта** от поиска: `<meta name="robots" … data-env="test">` в страницах
  и блок `test-noindex` в `.htaccess` (X-Robots-Tag). При деплое на прод deploy.yml
  удаляет их автоматически — руками ничего делать не нужно.
- Меняешь FAQ на странице — обнови JSON-LD FAQPage в `<head>`. Меняешь содержание — обнови `lastmod` в sitemap.xml.

## Страницы и сборка
- HTML правится в `src/pages/*.html` и `src/partials/*.html`, затем `python3 tools/build.py`
  собирает страницы в корень (index.html, kids.html…). Собранные файлы руками не править.
- Страницы программ: `kids.html` — вручную (`src/pages/kids.html`), остальные 10 (adults, business,
  politics, tech, other, hsk, hskk, yct, bct, csca) генерирует `tools/programs.py` из данных →
  `src/pages/<slug>.html`. Правка текстов: данные в programs.py → `python3 tools/programs.py && python3 tools/build.py`.
  Меняются только блоки 1–2 и результаты, остальное — общие фрагменты. Картинка первого экрана — `img/pages/<slug>/hero.webp`: превью из карточки программы в Figma (квадрат 720 px, рендер узла карточки ×5); у kids — своя из макета шаблона.
  Новая программа: добавить в PROGRAMS, картинку, ссылку с карточки на главной, строку в sitemap.xml.
- Страница «Об основателе» — `src/pages/founder.html`: история (текст №1 заказчицы) с выделенными словами —
  наведение увеличивает, нажатие открывает фото справа (на телефоне — окном), подписи из ТЗ.
- Иероглифы в шрифте Hanzi — подмножество Noto Sans SC: добавили новые иероглифы на любую страницу — пересобрать подмножество.
- Иконки «Наш подход» подбирать по смыслу текста карточки из наборов Iconify
  (npm `@iconify-json/*`), сохранять SVG в `img/icons/approach/` нужного цвета; список для страниц программ — `tools/icons.json`.

## Вёрстка
- Десктоп 1440 из Figma (файл `7x4TqNo1O1ycA3zA1S0kCO`, фрейм `287:15951`) — попиксельно.
- Мобильная 393 (фрейм `382:1925`): `@media (max-width: 1023.98px)`, колонка `--col` до 480 px.
  Декор внутри карточек — в единицах `--u` (1px макета от ширины карточки, `container-type: inline-size`).
  Мобильные картинки — `img/m/`, подключаются через `<picture><source media="(max-width: 1023px)">`.
- Планшет 600–1023 (макета нет, сделан по логике): слой `@media (min-width: 600px)` поверх мобильной
  версии — две колонки. Целевое устройство заказчицы — Galaxy Z Fold: внешний экран ~344 px (мобилка),
  раскрытый ~690×840 и горизонтально ~840 (планшет). Проверять 344 / 690 / 841 / 768.
- Мобильное меню — панель справа (`.drawer`, макет `593:313`).
- 1024–1439: десктоп масштабируется целиком (`zoom`, `--page-zoom` из JS).
- Скругления только токенами: `--r-xl` 40, `--r-md` 20, `--r-frame` 16, `--r-card` 13, `--r-sm` 10, `--r-pill`.
- Анимации спокойные, с учётом `prefers-reduced-motion`.

## Админка /admin.php (2026-10-12, переделана 2026-10-16: вид как в Notion, три языка, справка «Как пользоваться»)
- Вход: логин/пароль заказчицы (задаются один раз на хостинге через код настройки; смена пароля — во вкладке «Пароль»). Пароль в репозитории не хранится — только хэш кода настройки в admin.php.
- Вкладка «Заявки»: send.php дублирует каждую заявку в data/leads.php (на почту уходит только school@thousandli.ru, gmail убран).
- Вкладка «Тексты» (страницы — в меню слева): правка видимых текстов страниц прямо в готовых .html, по блокам страницы, языки — колонками; список правок — data/content.php. Цифры тоже правятся (цены); пробелы в ценах админка делает неразрывными. После деплоя workflow вызывает admin.php?reapply=1 и правки возвращаются. Менять исходники в src/ можно как раньше.
  - Список страниц в админке строится по файлам `*.html` в корне сайта (функция `pages()`): новая страница (src/pages/xxx.html → build.py) появляется во вкладке «Тексты» и в «заменить везде» сама; правки `admin.php` не нужны. Красивое название для списка — `PAGE_TITLES` в admin.php (иначе берётся `<h1>`).
  - Если текст в исходнике поменяли и правка из админки к нему уже не подходит (на странице нет ни исходного, ни правленого текста), при ближайшем возврате правок она переносится в `data/content_stale.php` и показывается на вкладке «Тексты» этой страницы («Не применились после обновления сайта») — внести заново. Ничего молча не пропадает и не «оживает» позже.
  - Менять текст в src/, который заказчица уже правила через админку, — значит сбросить её правку: лучше сначала посмотреть вкладку «Тексты» (пометка «изменено»).
- Папка data/ в git не попадает и деплоем не затрагивается; снаружи её файлы отдают 404.
- Не синхронизируется с админкой: JSON-LD (FAQ), title/description — их правим в src/.
- Стоимость (2026-10-16): под абонементами — к каким направлениям относятся цены, карточки «Специализированные направления» (ведёт Варвара, 5 000 ₽ за 1 ч 15 мин) и «Разговорный клуб» (`.xplan` в style.css).
  - Ловушка PHP: страница «404» — числовой ключ массива pages() (int). Перед h() и page_file() ключ приводить к строке (strict_types), иначе вкладка «Тексты» падает сразу после списка страниц. После любых правок admin.php проверять вкладку «Тексты» локально (php -S + вход).

## Языки: английский и китайский (en/, zh/)
- Версии `en/*.html` и `zh/*.html` (13 страниц: главная, программы, экзамены, основатель) собирает `tools/i18n.py`
  в конце `tools/build.py`. Документы (политика, согласие, cookie) и 404 — только на русском.
- Переводы — словари `tools/i18n/en.json` и `zh.json` ({"русский фрагмент": "перевод"}). Поменяли русский текст —
  `python3 tools/i18n.py --todo` → `tools/i18n/todo-<язык>.json`: что перевести, вписать в словарь, пересобрать.
- Переключатель RU / EN / 中文 — метки `<!-- lang-switch … -->` в `src/partials/header.html`; hreflang и sitemap.xml — тоже i18n.py.
- Ответы квиза (value) и название программы в заявке остаются русскими — их читает школа. Сообщения форм — словарь I18N в `js/main.js`.
  На en/zh телефон без маски, любой страны (10–15 цифр; send.php принимает так же).
- Админка (admin.php) правит все три языка: ключи правок в data/content.php — `index`, `en/index`, `zh/index`…
  Строки «русский → английский → китайский» и блоки страницы берёт из `admin-texts.php` (карта, её пишет i18n.py
  при сборке; в начале файла — заглушка 404, снаружи не открывается). Тексты без перевода (цены, цифры, HSK) —
  одно поле «Все языки», меняется на трёх версиях сразу. Перевод сам не меняется вслед за русским — админка
  подсказывает «проверьте перевод». После правки словаря i18n и пересборки правки заказчицы из админки
  возвращаются как обычно (reapply), устаревшие — в «Не применились».
- Видео основателя на en/ и zh/ — английская запись `video/founder-en.mp4` (замену делает i18n.py).
